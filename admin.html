חיבור לגיטהאב

כדי להוסיף חומרים צריך מפתח גישה (token) של גיטהאב. המפתח נשמר רק בדפדפן הזה.

איך יוצרים מפתח?
  1. נכנסים ל-יצירת מפתח חדש בגיטהאב.
  2. Token name: למשל math-website. ב-Expiration אפשר לבחור תוקף ארוך.
  3. Repository access: Only select repositories ← בוחרים math-website.
  4. Permissions ← Repository permissions ← Contents: Read and write.
  5. לוחצים Generate token, מעתיקים את המפתח ומדביקים כאן.
